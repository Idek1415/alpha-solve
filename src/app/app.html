@switch (helpSection()) { @case ('Getting started') {

Create a project with New, name its system, and enter inputs in the right panel. Add equation, Python function, or note cards below the calculations.

Click Run to solve the whole dependency system. Alpha Solve repeats the calculations until the shared variables stop changing, so a calculation can use a value produced by a later card. Results appear alongside each card and in Computed.

} @case ('Projects and files') {

New keeps your other projects in the explorer. Click a project name to switch; use its arrow to collapse or expand its systems. Each project can contain several systems. Delete a project with the × on its tab or its right-click menu; at least one project remains open.

Save writes the active project to an .asolve file. Open starts in Documents → Alpha Solve App and adds the chosen project to your explorer. A persistent notification displays the full saved path.

Autosave restores open projects on this computer. Save files separately for backups or sharing.

} @case ('Equations and variables') {

Define named inputs on the right and type those same names directly in equations. Parameter names use a math editor too: type an underscore to create a subscript, such as x_0. Typed or pasted Greek letters are stored as canonical names, so ρ_ox is shared with rho_ox throughout the system. A compound name such as ΔR is stored as DeltaR; use an explicit multiplication sign when Δ and R are separate variables.

Example: U = 0.5 × k × x_0². Type * for multiplication, / for fractions, ^ for powers, and _ for subscripts. Use arrow keys to leave a subscript or fraction.

When an equation or Python function references a name that is not an input, solver target, computed value, or output of any current or future card, a Possible missing inputs row appears. Click a variable to add it as an input, or leave it alone if it should remain an unknown. Nothing is added automatically.

Inputs and calculated values are shared across all calculations. Alpha Solve repeats dependency passes until no values or units change. Use explicit multiplication between names. Recognized SI input units are normalized and computed units are inferred dimensionally through products, quotients, powers, roots, and dimensionally consistent sums. Blank computed units indicate that the expression or one of its inputs could not be resolved dimensionally.

} @case ('Python functions') {

Write exactly one Python function. Its arguments match input names or calculated variables from anywhere in the system. Return a dictionary whose keys name the output variables.

def calculate(m, k):

Imports belong inside your function. Print output appears under Console output. Only run code from sources you trust. Runtime packages currently require an internet connection.

} @case ('Solver capabilities') {

The solver groups equations that share unknowns and solves those equations together. Add optional Solver targets in the right panel to specify a variable's initial guess and bounds. If symbolic solving has several valid answers, bounds or guesses select a branch. Numerical solving requires a guess for each unknown in its connected group. The app reports insufficient equations, conflicts, and ambiguous answers above the cards.

Input values using recognized SI units and prefixes are normalized to coherent SI before evaluation (for example, GPa to Pa). Derived equation units are inferred where dimensional relationships can be resolved; review complex models before using results.

} @case ('Arrange calculations') {

Drag the dotted handle at the left of a card onto another card to organize the calculation sequence. The arrow buttons remain available for keyboard users.

Right-click empty space among the cards to add an equation, Python function, or note at that location. Right-click a card to duplicate, rename, run, collapse, add below, or delete it. Right-click a system in Project Explorer for system actions.

Right-click an input or computed variable to find cards that reference its exact name. Click a result to jump to that card. Normal text editing menus remain available in input fields.

The arrow beside the handle collapses or expands a card. Dependency passes allow values to flow in either direction, while order still controls which calculation runs first. Undo and Redo reverse edits within the active project.

} @case ('JSON and LLMs') {

Export JSON creates the compact portable system file. LLM JSON creates a self-describing package containing the same system plus exact import shapes, identifier and subscript rules, value/unit-entry rules, dependency behavior, safety guidance, and solver capabilities. Both formats can be imported directly.

Imported code is not automatically executed. Review it before running. For reliable analysis, ask the LLM to verify assumptions and dimensional consistency rather than treating stored results as authoritative.
